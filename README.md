## 📖 A Evolução: De Solucell para Soluções SP

O projeto nasceu originalmente como **Solucell SP**, focado exclusivamente em assistência técnica express e customização de dispositivos móveis. Com o avanço da minha formação em Análise e Desenvolvimento de Sistemas (ADS) e a necessidade de resolver problemas mais complexos, a operação pivotou.

Hoje, a **Soluções SP** reflete uma jornada de resiliência e adaptação. Expandimos o modelo de "delivery de serviços" (inspirado na logística de entregas rápidas) para abranger engenharia de software e infraestrutura. Saímos do reparo de telas para a construção de bots, automação de tarefas e segurança da informação.

## 🚀 O que este repositório contém?

O ecossistema atual não se resume apenas a uma página web. Ele é a fundação dos serviços prestados:

1. **Frontend / Landing Page (UI/UX Futurista):**
   - Interface totalmente refatorada com HTML5 e Tailwind CSS.
   - Design focado em *Dark Mode* cinematográfico, alta conversão e carregamento ultrarrápido.
   - Integração direta com fluxos de atendimento via WhatsApp.

2. **Automação e Bots (Python):**
   - **Solutech Bot:** Aplicações desenvolvidas em Python (usando Streamlit e Flet) para automação de atendimento, catálogos flexíveis e interação com clientes.
   - **Hermes Agent:** Nossa camada de orquestração inteligente, responsável por rodar diagnósticos automatizados, monitoramento de sistemas e scripts de infraestrutura.

3. **Infraestrutura e Hardware:**
   - Serviços de *hardening*, limpeza e otimização de PCs baseados em metodologias ágeis e seguras.
   - Todo o sistema financeiro roda sobre pagamento instantâneo (Pix) validado pós-aprovação do serviço pelo cliente.

## 🛠️ Stack Tecnológico Dominado

- **Front-end:** HTML5, Tailwind CSS, JavaScript (DOM, ECMAScript).
- **Back-end & Automação:** Python, Java (POO), SQL.
- **Frameworks & Libs:** Streamlit, Flet, Pygame.
- **Deploy & Cloud:** Vercel.
